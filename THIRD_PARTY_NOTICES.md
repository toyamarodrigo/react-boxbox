# Third-party notices

Data this project ships, beyond its own code and the races it fetches (see the README).

## Circuit elevation

`src/data/circuit-elevation.ts` is generated by `bun run circuits:elevation`. It holds heights sampled
from the digital elevation models below, then smoothed and measured from each lap's lowest point,
so it is modified data. The Onboard view uses it and credits it in the Replay caption.

### NASA SRTM, via the AWS Terrain Tiles (Baku)

GLO-30 leaves out Azerbaijan, so the Baku City Circuit's heights come from the Shuttle Radar
Topography Mission (SRTM), a work of the U.S. government (NASA, NGA and USGS) in the public domain.
They are read from the "skadi" tiles of the Terrain Tiles on the AWS Open Data registry
(<https://registry.opendata.aws/terrain-tiles>, `s3://elevation-tiles-prod/`). SRTM data courtesy
of the U.S. Geological Survey.
